PS5 BUDDY 2 - low-lag PS5 play with a friend, PS5Upload + Tailscale
=====================================================================
For a jailbroken PS5 running the PS5Upload helper. The PS5 is on Tailscale
itself, so the game stream goes straight from the PS5's upload to you.

INSTALL (once)
  Unzip, double-click Install.bat (no admin needed).
  It installs PS5Upload (Tailscale built in) and PS5 Buddy, then opens it.

FRIEND -> "Play" tab
  1. Turn on Tailscale  (sign in with the account the host invited)
  2. Paste the host's invite code > Use invite
  3. Test line  -> shows the best quality your line + the host's upload can hold
  4. PLAY  -> starts PS5Upload at exactly that quality; watch/play it in
     PS5Upload > Play. "Auto-lower on stutter" steps the quality down by
     itself if the stream keeps losing packets.
  First time only: PS5Upload > Play > Set up (pairing, PIN from the PS5).
  Speed boost: top priority for PS5Upload's traffic on your PC (asks for admin once).

HOST -> "Host" tab
  1. Check: PS5 on Tailscale? (PS5Upload > Connection > PS5 card > Put this PS5 on Tailscale)
  2. Measure your upload (the PS5 sends the stream on it)
  3. Copy invite code -> send it; also PS5Upload > Connection > Invite a device
  4. Playing together on one stream instead? Start Play + Play Together in
     PS5Upload and tick "Watch guests" to see each guest's ping.

LEAST LAG: PS5 on ethernet, both PCs on ethernet, USB controller.
Remove: Uninstall.bat (or Settings > Apps > PS5 Buddy)
